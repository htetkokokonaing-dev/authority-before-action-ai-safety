# Project Description

Zenodo DOI: https://doi.org/10.5281/zenodo.20541041

This repository is the companion project repository for **Authority Before Action: A Conditional Failure-Chain Framework for Tool-Using AI Safety**.

The paper presents a conceptual and operational framework with a reproducible benchmark specification. It does not report executed benchmark results or claim deployment safety.

The framework develops a conditional failure-chain account of tool-using artificial intelligence systems. It argues that prompt injection and related adversarial failures become operationally dangerous when untrusted content receives inappropriate authority and crosses an externally consequential boundary as output, tool execution, memory update, workflow action, or policy-relevant signal.

The repository includes the final paper files, extracted figures, citation metadata, benchmark schema files, and documentation for future benchmark implementation.
